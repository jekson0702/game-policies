Политика конфиденциальности

Игра «Тихая уборка» / Quiet Cleaning для Android. Идентификатор приложения: com.quietcleaning.game.

Дата редакции: 15 ноября 2026 года.

1. Разработчик и контакты

Разработчик — Яковец Евгений Викторович, физическое лицо, Беларусь. По вопросам работы игры и обработки данных: yakavets.yauheni@gmail.com.

Политика относится к самостоятельной Android-версии игры. Она не описывает отдельную браузерную версию на платформе Яндекс Игры.

2. Что хранится на устройстве

Игра не требует регистрации. Прогресс, покупки за игровую валюту, достижения, настройки языка и звука и подтверждения рекламных наград сохраняются в приватном хранилище приложения на устройстве.

Разработчик не получает эти сохранения автоматически и не синхронизирует их с собственным сервером или другими устройствами. Данные хранятся до сброса прогресса, очистки данных или удаления приложения. Сброс прогресса внутри игры сохраняет настройки языка и звука; очистка данных приложения удаляет и их. Обычное обновление с тем же идентификатором и совместимой подписью сохраняет данные.

Резервное копирование игровых файлов отключено в настройках приложения. Поведение отдельных средств переноса между устройствами может зависеть от производителя Android.

3. Реклама и сторонние компоненты

Для загрузки и показа рекламы используется Yandex Mobile Ads SDK, включая необходимые ему компоненты AppMetrica. Они обеспечивают работу рекламы, учёт рекламных событий, техническую диагностику и защиту от недействительной активности. SDK Яндекс Игр, аккаунты игроков и облачные сохранения этой платформы не используются.

Реклама с вознаграждением показывается по запросу игрока — для бустера дохода или открытия темы. Рекламный SDK при этом может инициализироваться и предварительно загружать объявления при запуске игры, ещё до нажатия кнопки просмотра. Основной игровой процесс доступен без интернета.

При обращении к рекламным сервисам могут обрабатываться IP-адрес, технические сведения об устройстве, операционной системе и приложении, служебные идентификаторы SDK, сведения о загрузках, показах и взаимодействиях с рекламой. Конкретный объём зависит от версии SDK и его настроек. Разработчик не передаёт SDK игровой баланс, маски очищенного пола, имя игрока или данные аккаунта Яндекс Игр.

В текущей конфигурации включён режим ограничения сбора данных по возрасту, не передаётся согласие на персонализацию рекламы и отключено отслеживание местоположения. Разрешения Android на геолокацию и доступ к рекламному идентификатору AD_ID отсутствуют. Это не исключает технический сетевой обмен, необходимый для работы рекламного сервиса.

Обработка рекламным провайдером, включая сроки хранения, получателей и порядок обращения по поводу его данных, описана в политике конфиденциальности Яндекса. Информация о режимах SDK: ограничение сбора данных по возрасту.

Создано с использованием Yandex Mobile Ads SDK. Лицензионное соглашение SDK.

4. Обращения в поддержку

Если вы добровольно пишете в поддержку, разработчик получает адрес отправителя, текст обращения и отправленные вами вложения. Эти сведения используются для ответа, решения вопроса и необходимого последующего сопровождения этого обращения.

Переписка хранится, пока она необходима для этих целей, после чего удаляется из почты разработчика, если для конкретного обращения не требуется дальнейшее хранение по применимому законодательству. Можно обратиться с запросом об удалении переписки. Не отправляйте пароли или документы, которые не нужны для решения вопроса.

Для почты используется Gmail. Обработка данных почтовым сервисом регулируется также политикой конфиденциальности Google.

5. Дети и возможности пользователя

Игра предназначена для широкой аудитории, включая детей, и не позиционируется исключительно как детская. Указанные ограничения рекламного SDK применяются ко всем игрокам. Игра не запрашивает имя, дату рождения, телефон или контакты ребёнка. Родители и законные представители могут обращаться к разработчику по вопросам данных ребёнка.

Просмотр рекламы для получения бонуса доброволен. Чтобы удалить локальный прогресс, используйте сброс в настройках игры. Чтобы удалить все локальные данные, включая настройки, очистите данные приложения в Android или удалите игру.

По вопросам доступа к данным, их уточнения, удаления и прекращения обработки в применимых случаях напишите на почту поддержки. Для данных, обрабатываемых Яндексом, Google или GitHub, также доступны способы обращения из политик соответствующих сервисов. Удаление игры не удаляет автоматически данные, которые эти сервисы обрабатывают самостоятельно.

6. Размещение политики и сторонние сервисы

Страница политики размещена на GitHub Pages, без добавленных разработчиком систем аналитики. При открытии страницы GitHub может обрабатывать технические сведения о запросе в соответствии со своей политикой конфиденциальности.

Использование сервисов Яндекса, Google и GitHub может включать обработку данных за пределами страны пользователя. Условия обработки и получатели определяются также документами этих провайдеров, указанными выше.

7. Изменения политики

При изменении функций игры или обработки данных политика обновляется. Дата редакции указана в начале документа. Актуальная версия доступна по ссылке из приложения и карточки игры в RuStore.
